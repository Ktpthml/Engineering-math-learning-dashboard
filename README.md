# Engineering Math Progress Dashboard

A beautiful, interactive dashboard to track your journey through engineering mathematics - from basic arithmetic to advanced concepts.

## Features

✨ **Interactive Progress Tracking**
- Track all 8 modules of the engineering math course
- Mark topics as learned and practice items as completed
- Visual progress bars and completion percentages
- Real-time statistics dashboard

📝 **Personal Learning Notes**
- Add notes and reflections for each module
- Track difficulties and key concepts
- Store your learning journey

💾 **Data Persistence**
- All progress saved in your browser (localStorage)
- Download your progress as JSON anytime
- Backup and restore functionality

📱 **Responsive Design**
- Works on desktop, tablet, and mobile
- Beautiful gradient UI with smooth animations
- Easy to navigate and use

## Quick Start

### Option 1: Use Directly (Easiest)
Just open the `engineering-math-dashboard.html` file in your browser!

### Option 2: GitHub Pages Hosting (Recommended)

1. **Fork or Clone this Repository**
   ```bash
   git clone https://github.com/Ktpthml/engineering-math-dashboard.git
   cd engineering-math-dashboard
   ```

2. **Enable GitHub Pages**
   - Go to Settings → Pages
   - Select "Deploy from a branch"
   - Choose `main` branch and `/root` folder
   - Save

3. **Access Your Dashboard**
   - Visit: `[https://Ktpthml.github.io/engineering-math-dashboard/](https://ktpthml.github.io/Engineering-math-learning-dashboard/)`
   - Your progress syncs across all devices!

## How to Use

### Starting a Module
1. Click on any module to expand it
2. See all topics and practice items
3. Start learning from the course material

### Tracking Progress
1. Check off topics as you complete them
2. Mark practice items when finished
3. Watch your progress bar fill up

### Taking Notes
1. Expand a module
2. Scroll to the notes section
3. Write your thoughts, questions, or struggles
4. Notes auto-save!

### Backing Up Progress
1. Click "💾 Download Progress" button
2. Your progress saves as a JSON file
3. Keep it safe for backup

### Resetting (if needed)
1. Click "🔄 Reset All Progress"
2. Confirm the action
3. Start fresh!

## Support

Having issues? Try these:

**Dashboard not responding:**
- Refresh the page (F5)
- Clear browser cache
- Try a different browser

**Progress not saving:**
- Check if localStorage is enabled
- Try clearing browser storage partially
- Download your progress before major browser updates

**Can't see modules expanding:**
- Update your browser
- Clear browser cache
- Try incognito/private mode
